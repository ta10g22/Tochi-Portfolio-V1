# Tochi's Portfolio

A personal portfolio website showcasing my software, machine-learning, embedded-systems, and digital-hardware projects.

Built with HTML, CSS, and a small JavaScript contact-form handler. The layout adapts to phones, tablets, and laptops, and project cards link to their source repositories.

The contact form opens a draft in the visitor's email app. It does not send messages through a server.

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Updating styles

Update the version in the stylesheet and script URLs in `index.html` when changing those files so returning visitors receive the latest assets. Images have explicit dimensions to keep navigation icons small even before the stylesheet loads.
